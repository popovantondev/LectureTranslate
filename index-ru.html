LectureTranslate

Переводит немецкие SRT-субтитры на русский с сохранением таймкодов, очередью и проверкой черновика.

Выпуск · 3.5.1 macOS 15+ · Apple Silicon
Скачать для macOS Исходный код Swift · SwiftUI Руководство ↗

Перед запускомНужны отдельное подключение и вход во внешний сервис перевода. FFmpeg/ffprobe необязательны для отдельных медиафункций.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из «Первых шагов» и инструкции по сборке, в Терминале.

$ shasum -a 256 lecture_translate-v3.5.1-app.zip
# Сверить значение с SHA256SUMS из релиза
$ unzip lecture_translate-v3.5.1-app.zip
# Приложение не нотаризовано: при первом открытии macOS может предупредить
# Настроить подключение к сервису перевода по руководству
→ Добавить немецкие .srt, выбрать профиль, запустить очередь

Внешний сервис

Перевод и проверка идут через внешний сервис: тексты субтитров передаются по выполненному входу. Очередь, журналы и проекты остаются локально на Mac.

Проверено

  • Автоматические проверки в GitHub Actions (macOS 15): тесты, предварительная сборка, проверки релиза и экспорта
  • По данным проекта — 2473 локальные офлайн-проверки, в том числе 14 проверок релиза
  • Проверены двенадцать синтетических демо-окон (3 языка × 2 темы × 2 размера)
  • Контрольные суммы SHA-256 (SHA256SUMS) и manifest.json в релизе
  • Версия 3.5.1 и журнал изменений

Как это работает

  1. Открыть SRT
  2. Подключить сервис перевода
  3. Сохранить перевод SRT
