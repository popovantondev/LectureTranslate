LectureTranslate

Translate German SRT subtitles into Russian with preserved timecodes, a queue and draft review.

Release · 3.5.1 macOS 15+ · Apple Silicon
Download for macOS Source code Swift · SwiftUI User guide ↗

Before you startRequires a separate connection and sign-in to an external translation service. FFmpeg/ffprobe are optional for specific media features.

What's inside

Installation, features, data flow and checks.

Installation

The steps from “First steps” and the build guide, in Terminal.

$ shasum -a 256 lecture_translate-v3.5.1-app.zip
# Compare the value with SHA256SUMS from the release
$ unzip lecture_translate-v3.5.1-app.zip
# App is not notarized: macOS may warn on first launch
# Set up the connection to the translation service as described in the guide
→ Add German .srt files, choose a profile, start the queue

External service

Translation and review go through an external service: the subtitle text is sent over the signed-in connection. Queue, logs and projects stay local on the Mac.

Sign-in requiredText is sent to the service
