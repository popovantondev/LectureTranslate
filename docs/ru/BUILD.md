# Сборка и локальные тесты

## Требования

macOS 15 или новее, Apple Silicon, Apple Command Line Tools (Swift), Bash и Ruby. Для перевода и проверки нужен установленный Codex CLI с авторизацией через ChatGPT. Локальные сборка и тесты не вызывают модели. FFmpeg/ffprobe необязательны и нужны только некоторым функциям работы с медиа.

## Состояние этой копии

`VERSION`, `BUILD_NUMBER` и `Info.plist` согласованы: **3.5.1 / build 16**. Предыдущий сохранённый релиз — 3.4.3 / build 13; старые каталоги релизов не изменяются.

Полный офлайн-прогон: 2473 локальные проверки, включая 64 проверки видео и 14 проверок выпуска. Получены 12 demo-окон (3 языка × 2 темы × 2 размера); отдельно проверены настройки, замечания, пакетный экспорт, замена с резервом и сохранение/возобновление проекта. Использовались только искусственные данные.

## Локальные команды

В каталоге проекта:

```sh
bash Scripts/test-all.sh
bash Scripts/build.sh --preview
```

Проверки используют искусственные данные и изолированное временное состояние. Они не запускают перевод, не читают аккаунт и не изменяют пользовательские данные.

- `bash Scripts/test-all.sh` — полный набор локальных проверок.
- `bash Scripts/test-model.sh` — пауза и продолжение в изолированной очереди, без запросов к модели.
- `bash Scripts/test-quota.sh` — проверка пути CLI, диагностики, тайм-аута и отмены на локальных фикстурах.
- `bash Scripts/test-speech.sh` — локальная проверка чисел, единиц, сокращений и символов для озвучки.
- `bash Scripts/test-project.sh` — сохранение, проверка целостности и открытие `.lectureproject`.
- `bash Scripts/test-instance-lock.sh` — блокировка экземпляра и поиск владельца.
- `ruby Tests/ReleaseTests.rb` — проверки архивации и выпуска без моделей.
- `bash Scripts/build.sh --preview` — изолированная пробная программа в `.build`; папки релизов не перезаписываются.

Не редактируйте вручную существующие `dist/vX.Y.Z` и `releases/vX.Y.Z`. Скрипты выпуска отказываются перезаписывать существующую цель.

## Предупреждение macOS

Планируемый ZIP не подписан Developer ID и не нотариализован Apple; при первом открытии macOS может показать предупреждение. Локальная ad-hoc подпись не заменяет Developer ID и нотариализацию.
